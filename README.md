# Performance Evaluation of 5G OTFS Systems under Realistic Fading Channels

## Objective
To evaluate the performance of Orthogonal Time Frequency Space (OTFS) modulation under realistic fading channel conditions and compare it with conventional communication techniques.

## Tools Used
- MATLAB
- Communication System Simulation

## Methodology
- Implemented OTFS modulation and demodulation.
- Simulated wireless fading environments.
- Evaluated Bit Error Rate (BER) performance under varying SNR conditions.

## Results
The simulation demonstrated the robustness of OTFS in high-mobility wireless environments and its improved BER performance under fading channels.

## Future Scope
Real-time implementation using SDR platforms and integration with next-generation wireless communication systems.
